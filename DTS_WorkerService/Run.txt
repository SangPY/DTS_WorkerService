1. Windows Service phải publish (không dùng bin/debug)
Right click project → Publish → Folder -> Finish . 
Edit dotnet publish -c Release -r win-x64 --self-contained false
Nhớ nhấn Public tạo folder vật lý
2. Cài Windows Service bằng sc
Mở CMD Admin:
sc create DTS_WorkerService binPath= "D:\DTS\DTS_WorkerService\DTS_WorkerService\bin\Release\net8.0\publish\DTS_WorkerService.exe"
sc create DTS_WorkerService binPath= "D:\DTS\DTS_WorkerService\DTS_WorkerService\bin\Release\net8.0\publish\DTS_WorkerService.exe" start="demand" displayname="DTS worker service"

sc create DTS_WorkerService binPath= "D:\DTS\DTS_WorkerService\DTS_WorkerService\bin\Release\net8.0\publish\win-x64\DTS_WorkerService.exe" start= demand displayname= "DTS worker service"

3. Start service
cd D:\DTS\DTS_WorkerService\DTS_WorkerService\bin\Release\net8.0\publish\
net start DTS_WorkerService
sc start DTS_WorkerService
4. Lệnh xoá service khi cần
sc delete DTS_WorkerService
5. Kiểm tra service đang trỏ tới path nào
sc qc DTS_WorkerService
D:\DTS\DTS_WorkerService\DTS_WorkerService\bin\Release\net8.0\publish\DTS_WorkerService.exe
6.Kiểm tra service đã tạo chưa
sc query DTS_WorkerService
